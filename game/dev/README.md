# game/dev/

**What lives here:** tools for developers: stress tests, the debug overlay and preset villages. Nothing in this folder goes into the export.

- `test_runner/`: runs every test script of the new game with no window. See [docs/testing.md](../../docs/testing.md).
- `stress/`: the batch demo, the batch stress scene and the meeple pixel comparison. See [stress/README.md](stress/README.md).
- `village_demo/`: two villages tick side by side, to watch the simulation of #60 run. See [its page](village_demo/README.md).
- `worldgen/`: the world generation timing, a look at a whole world, and the comparison of the trees, rocks and bushes with the jam game. See [its page](worldgen/README.md).

Built by: #48, #61, #74, #31 and #32. The rules for this folder are in [game/README.md](../README.md).
